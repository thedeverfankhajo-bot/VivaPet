# Changelog

## 1.1.0
- Added temporary hide/show/toggle controls without losing the saved pet selection.
- Added /pet active status and clearer active/selected/locked states in /pet list.
- Added bounded horizontal and vertical follow offsets for custom models.
- Smoothed follow movement near the owner to reduce oscillation.
- Ensured configured effect durations cover the configured refresh interval.
- Expanded command and configuration documentation.

## 1.0.0
- Initial PocketMine-MP API 5 implementation.
- Added custom fox, dragon, owl and rabbit companions.
- Added rank permissions, following, configurable effects, persistence and resource-pack installation.
